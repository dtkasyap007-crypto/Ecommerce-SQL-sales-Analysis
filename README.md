# Ecommerce-SQL-sales-Analysis
SQL analysis of E-commerce customer, product, and order data using MySQL
## Project Overview
This project analysis e-commerce sales data to understand customer purchase, product performance, and revenue generation.
## Tools Used
- My SQL
- My SQL Workbench
- GitHub
  ## Database Tables
  - Customers
  - Orders
  - Products
  ## SQL Concepts Used
  - Select
  - Where
  - Inner Join
  - Group By
  - Order By
  - Aggregate Functions (SUM)
  - Aliases
  - Calculated Columns
  ## Key Analysis
  - Calculated total revenue generated by each customer.
  - Identified top Customers based on total revenue.
  - Analyzed product sales and quantities.
  - Compared product performance using order data.
  - Used JOINs to combine customer, order, and product information.
  ## Project Goal
  To use SQL queries to extract meaningful business insights from e-commerce sales data and demonstrate practical SQL data analysis skills.
